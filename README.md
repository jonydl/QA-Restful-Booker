# Project Overview
This is a project for learning Playwright and Typescript for testing manual, API, UI automation and integration.
I will be testing a hotel booking website and its API:
- UI: await page.getByText('Welcome to Shady Meadows B&BWelcome to Shady Meadows, a delightful Bed &').click();/
- API documentation: https://restful-booker.herokuapp.com/apidoc/index.html

- Note: This is not a real website and has been created for learning purposes by Mark Winterngam
- Note 2: The website might be offline at some point and unfortunately I can't guarantee the availability of the website in the future.

# Functional Requirements
A hotel website that allows users to view available rooms, book rooms within available dates and contact the hotel.
1. User view all available rooms
2. User will see available rooms based on check-in and check-out dates
3. User can book a room by filling the form
4. Booking confirmation is displayed
5. User can contact the hotel submitting the contact form
